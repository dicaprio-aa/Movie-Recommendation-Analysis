# Movie Recommendation and User Behaviour Analysis

A movie-rating analytics dashboard and hybrid recommendation system built with Python, Apache Kafka, Apache Spark Structured Streaming, and Streamlit.

The project uses the MovieLens Latest Small dataset to explore movie ratings, analyze user rating behaviour, and generate personalized movie recommendations.

## Features

- Clean and preprocess movie, rating, and tag datasets.
- Publish rating events to the Kafka topic `movie-ratings`.
- Process Kafka events with Spark Structured Streaming.
- Explore popular movies, genres, and rating distributions.
- Analyze an individual user's rating activity.
- Generate hybrid movie recommendations.
- View processed streaming activity in a Streamlit dashboard.

## Prerequisites

- Python
- Java (required by PySpark)
- Apache Kafka
- MovieLens Latest Small dataset

Kafka should be available locally at `localhost:9092`. The included batch file was prepared for a Windows setup and may need its Kafka installation path adjusted.

## Installation (Windows)

### 1. Clone the repository

```powershell
git clone https://github.com/dicaprio-aa/Movie-Recommendation-Analysis.git
cd Movie-Recommendation-Analysis
```

### 2. Create and activate a virtual environment

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, try:

```powershell
.\.venv\Scripts\activate.bat
```

### 3. Install dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Add the dataset

Download **MovieLens Latest Small** from:

https://grouplens.org/datasets/movielens/

Extract its CSV files into the project's `data/` folder. The preprocessing script expects `movies.csv`, `ratings.csv`, `tags.csv`, and `link.csv`.

### 5. Preprocess the data

```powershell
python prepare_data.py
```

This creates the cleaned CSV files used by the dashboard and recommender.

## Running the Project

Start the Kafka broker first and make sure it is listening at `localhost:9092`.

Create the topic once if it does not already exist:

```powershell
cd C:\kafka
.\bin\windows\kafka-topics.bat --create --topic movie-ratings --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
```

Then open separate terminals in the project folder, activate the virtual environment, and run:

**Terminal 1 – Spark streaming**

```powershell
python spark_stream.py
```

**Terminal 2 – Kafka producer**

```powershell
python producer.py
```

**Terminal 3 – Streamlit dashboard**

```powershell
streamlit run app.py
```

Open the dashboard at http://localhost:8501.

Alternatively, try `START_PROJECT.bat` on the Windows environment it was designed for. Adjust the Kafka path inside the batch file if Kafka is installed somewhere other than `C:\kafka`.

## Dashboard Pages

1. **Dashboard Overview** – dataset totals, average rating, rating distribution, and popular movies.
2. **Movie Analytics** – genre insights and movie search.
3. **User Behaviour** – rating activity and preferences for a selected user.
4. **Recommendations** – personalized movie recommendations.
5. **Live Activity** – processed Kafka events written by Spark.

## Hybrid Recommendation Method

The recommender combines:

- **Content-based filtering:** uses movie genres with TF-IDF and cosine similarity.
- **Collaborative filtering:** uses similarities in users' movie-rating patterns.

The current weighted formula is:

```text
Hybrid Score = 0.60 × Content Score + 0.40 × Collaborative Score
```

Movies already rated by the selected user are excluded from the recommendations.

## Dataset and Streaming Note

MovieLens Latest Small contains historical ratings and tags, not actual live viewing history. This project replays selected historical rating records as simulated streaming events. The Live Activity page displays records processed from that Kafka stream.

The recommender currently uses the cleaned historical dataset. Incoming streaming events do not automatically retrain or update the recommendation model in real time.
